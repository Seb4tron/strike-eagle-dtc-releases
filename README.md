# Strike Eagle DTC (unofficial) - releases

Plan the data cartridge for the DCS F-15E Strike Eagle on a map: routes, targets, offset and aim points, radios, MFD pages, release
programs and shapes, exported as a DTC for DCS file. This repository only hosts the downloadable releases.

**Download:** open the [latest release](https://github.com/Seb4tron/strike-eagle-dtc-releases/releases/latest) and download **`strike-eagle-dtc-<version>.zip`** under *Assets*,
then follow `INSTALL.md` inside the ZIP.

> **Do not use the "Source code (zip)" or "Source code (tar.gz)" links** that GitHub adds below it, and not the green *Code* button of
> this page: they only contain this README and `latest.json`, not the program. The program is the ZIP file named above.

> **Unofficial.** A community project, not affiliated with, endorsed by or supported by Eagle Dynamics or the authors of other DCS mods.
> The packages contain no game assets; everything the tool reads comes from your own DCS installation.

`latest.json` tells the tool which version is the newest one. Reading it is a plain GET request, nothing is sent.
